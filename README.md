# Beauty & Wellness E-Commerce Analytics

### Customer Behavior and Product Performance Analysis

## 📌 Project Overview
This project focuses on analyzing customer behaviour and product performance in the Beauty and Wellness E-Commerce industry using Python and Data Science techniques.

The project uses e-commerce event data to understand customer interactions, product popularity, brand performance, and pricing patterns.

## 🎯 Objectives
- Analyze customer shopping behaviour.
- Identify popular products and brands.
- Understand product price distribution.
- Explore customer activities such as views, cart additions, and purchases.
- Clean and preprocess raw e-commerce data.
- Prepare data for further analysis and machine learning.

## 📂 Dataset Information
The dataset contains five monthly CSV files:
- October
- November
- December
- January
- February

### Dataset Columns
- `event_time` – Date and time of customer activity.
- `event_type` – Type of event (view, cart, purchase).
- `product_id` – Unique product identifier.
- `category_id` – Product category identifier.
- `category_code` – Product category name.
- `brand` – Product brand.
- `price` – Product price.
- `user_id` – Customer identifier.
- `user_session` – Customer session identifier.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## ⚙️ Project Workflow
1. Import required Python libraries.
2. Load five monthly CSV datasets.
3. Combine datasets using Pandas.
4. Perform data cleaning.
5. Handle missing values and duplicate records.
6. Detect and handle price outliers.
7. Perform data normalization.
8. Conduct Exploratory Data Analysis (EDA).
9. Visualize customer and product behaviour.
10. Prepare cleaned data for further analysis.

## 📊 Expected Outcomes
- Better understanding of customer shopping patterns.
- Identification of popular brands and products.
- Insights into product pricing.
- Improved data quality.
- Prepared dataset for future machine learning applications.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Install the required Python libraries.
3. Upload the dataset CSV files.
4. Open `Beauty_Project.ipynb` in Jupyter Notebook or Google Colab.
5. Run all cells sequentially.
